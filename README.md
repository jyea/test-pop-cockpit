# 中国人口版图驾驶舱

打开 `index.html` 即可浏览总览、流动与分型三个页面。脚本、地图和数据均随目录提供。发布时以本目录为站点根目录，保留 `assets/` 的相对位置。

## 数据来源与统计口径

| 指标 | 来源与口径 |
| --- | --- |
| 常住人口 | 据《中国人口和就业统计年鉴 2024》整理。覆盖大陆 31 个省级行政区，年份为 1990–2023 年，单位为万人。指标为年末常住人口。缺失值记为 `null`，全国合计仅累加当年有值的省份，覆盖数见页面提示。 |
| 跨省流动人口 | 据 2020 年第七次全国人口普查整理。930 条有向记录按户籍省份 → 现住省份汇总，单位为人。迁入、迁出按这一方向归集，净流入为迁入减迁出，换算为万人并保留一位小数。这些指标描述普查时点的户籍地与现住地差异。 |
| 人口密度 | 2020 年人口除以等积投影下的省域面积，单位为人/平方千米，保留一位小数。 |
| 省份分型 | 使用 2010–2020 年人口增长率、净流入率和人口密度进行 K-Means 四类聚类。页面展示各类省份及其特征标签。 |
| 地图底图 | 省级 GeoJSON，随附地图文件标注来源为 DataV.GeoAtlas。地图中心坐标用于绘制省际流向。 |

## 发布文件

- `index.html` 为页面入口，`data.js` 包含人口序列、全部省际汇总流向及派生指标。
- `assets/cockpit.js` 提供交互逻辑，`assets/echarts.min.js` 用于图表渲染，`assets/china.js` 提供省级地图。
